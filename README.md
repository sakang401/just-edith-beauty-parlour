JUST EDITH BEAUTY PARLOUR

Updates in this build:
- User notifications open in a modal.
- Store opens in a modal.
- Admin can upload a home background image.
- Admin can upload an image/avatar for each service.
- Service images on the website are clickable and open a large zoom-style preview.
- Services are loaded from the database so admin-uploaded images appear on the site.

XAMPP:
1. Extract to C:\xampp\htdocs\justedith-beauty-parlour
2. Start Apache and MySQL.
3. Import database/justedith.sql if setting up fresh. Existing databases receive a lightweight compatibility migration when the PHP API runs.
4. For Vite development, run npm install in frontend, then npm run dev.
